# PS AI Image Hub v1.1.0 Compat integration

Development candidate integrated from the manually tested no-Effects-Lab UI
working copy. Panel, Manifest and current package version: 1.1.0.
Formal identity remains com.psai.imagehub.compat.cep11.panel; all existing
ps-ai-image-hub.compat.cep11 keys and PSAIImageHubCompat USER_DATA remain.
No Lab storage is read or migrated. No real API, commit, push or release.

Features: optional auto sharpen, History capacity and lazy thumbnails, Persistent
Panel, Generate below prompt, collapsible advanced/result sections and explicit
original re-import with stable-layer sharpening. No Effects Lab, Glow or Color Fusion.

Persistent Panel keeps UI state while the same Photoshop process remains alive.
A full Photoshop exit, crash, process restart, or explicit **Reload Plugin UI**
recreates the interface; persisted preferences/data survive independently.

Before integration the dirty v1.0.4 hotfix source, tests and scripts were copied
to outputs/snapshots/pre-v1.1.0-integration-20261102. Source tests for the old
Workspace-ID-only contract are updated to the newer dedicated-API-Host contract;
legacy llm-ID configuration migration remains covered. Lab coexistence assertions
now verify official Compat identity and exclusion of Lab namespaces. No test is
removed or newly skipped. Existing v1.0.3 release artifacts are untouched and
are not v1.1.0 artifacts. No installer or public candidate was built this round.

Manual acceptance required on the official Compat staging: verify existing API
keys/providers/presets/history load, Generate/Cancel, PNG/JPEG, selected-region
safety, sharpen modes, History original re-import, deleted-layer reimport, advanced
preferences and persistent panel reload. PS23/24 remain static/simulated only.

## Bundled repair presets

Ten presets from the user-provided 超清修复提示词模板包_插件兼容版.zip
are bundled as a normalized, local JavaScript data catalog, with stable reserved
builtin-ultra-repair IDs. Prompt text, categories and parameters are preserved.
The app explicitly supplies the trusted catalog to the Registry. It is merged
into the in-memory library without copying it into user preset storage or
rewriting imported presets. Existing user IDs win on collisions. Imported
preset deletion rebuilds the merged view so built-ins remain available.
Built-in deletion uses the existing hiddenFactoryPresetIds mechanism; restart
keeps it hidden, and Restore Built-ins explicitly makes it visible again.
No network request, API key or image processing is involved.
